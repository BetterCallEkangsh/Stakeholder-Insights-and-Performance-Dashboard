# Stakeholder Insights and Performance Dashboard

A business intelligence dashboard built to give stakeholders a consolidated, interactive view of insurer performance, premium trends, profitability, and asset distribution — enabling faster, data-driven decision-making.

![Dashboard Preview](Dashboard_1.png)

## 📌 Overview

The **Stakeholder Insights and Performance Dashboard** consolidates data across insurers, stakeholders, cities, and policy tenures into a single interactive view. It helps business and finance teams:

- Track how much value each insurer or stakeholder group is generating
- Monitor premium collection trends over time
- Understand shareholding composition across stakeholder types
- Evaluate profitability against cost ratios
- Break down asset distribution across stakeholder categories

## 🎯 Purpose

This dashboard provides a comprehensive view of key business metrics and data insights related to stakeholders, insurers, and policy performance — allowing users to analyse premium trends, profitability, and asset distribution to make informed, data-driven decisions.

## ✨ Key Features

### 📊 Charts & Visualizations
- **Value Created by Insurers** — bar chart comparing total value generated across insurer categories (Bancassurance partners, Broker, Corporate agent, Employee, Lives cover, Partner branches)
- **Premium Collected Over Time** — stacked trend chart of premium types (First year, Renewal, Single premium) from 2014–2024
- **Shareholding Partners vs Stakeholder Distribution** — pie chart of ownership split (DII, FII, Promoters, Retail)
- **Cost Ratio vs Profitability** — comparison of Commission, Opex, and Total cost ratios against Net Worth and Profit After Tax
- **Profitability by City and Tenure** — matrix view of profitability across cities, segmented by policy tenure buckets (1–3, 3–5, less than 1, more than 5 years)
- **Count of Assets Under Management vs Stakeholders** — distribution of Debt/Equity assets across stakeholder categories (People, Distributors, Customers, Investors, Community, Environment, Premises)

### 📈 Key Performance Indicators (KPIs)
| KPI | Description |
|---|---|
| **Total Premium Collected** | Sum of all premiums collected across all periods |
| **Average Age of Stakeholders** | Mean age across the stakeholder base |
| **Value Created under Equity** | Total value created where Assets Under Management = "Equity" |
| **Highest Value Created by Insurer** | Peak value generated by a single insurer |

### 🔍 Filters
- **City** — narrow the view to specific regions
- **Stakeholder** — analyse contribution by stakeholder type
- **Policy Tenure** — range-based filtering on policy duration
- **Month / Year of Data** — date range filtering
- **Gender** — demographic-level filtering
- **Profitability** — filter by profitability bands

### 🖱️ Interactivity
- Cross-filtering: clicking any chart dynamically filters all other visuals
- Hover tooltips with detailed data on demand
- KPIs and filters update in real time based on selections

### 📤 Export
- **Download PDF** button to export the full dashboard
- Export captures all visible charts, KPIs, and applied filters
- Includes a light company-branded watermark on the exported PDF

## 🗂️ Dashboard Sections

1. **Header** — Title bar with company branding and PDF export button
2. **KPI Strip** — Average Age, Value Created under Equity, Highest Value by Insurer, Total Premium Collected
3. **Filters Panel** — City, Stakeholder, Policy Tenure, Date, Gender, Profitability
4. **Core Visuals Row** — Value Created by Insurers, Premium Collected Overtime, Profitability by City & Tenure, Assets Under Management vs Stakeholders
5. **Shareholding Partners vs Stakeholder Distribution** — pie chart section
6. **Cost Ratio vs Profitability** — comparative ratio analysis section
